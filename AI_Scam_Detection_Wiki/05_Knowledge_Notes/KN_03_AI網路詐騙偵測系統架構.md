# KN_03：AI 網路詐騙偵測系統架構

## 一、專題介紹

本專題以 AI 網路詐騙偵測系統為主題，結合自然語言處理（NLP）及機器學習技術，設計一套可以分析可疑訊息並提供風險提醒的系統。

系統主要分析使用者輸入的文字內容，透過文字前處理、特徵擷取及分類模型，判斷訊息是否具有詐騙風險。

## 二、系統研究目標

1. 建立正常訊息及詐騙訊息資料集。
    
2. 利用 NLP 分析訊息文字特徵。
    
3. 使用機器學習建立分類模型。
    
4. 比較不同模型的偵測效果。
    
5. 將分析結果轉換成使用者容易理解的風險提醒。
    

## 三、系統架構

本專題規劃六個主要階段：

### 第一階段：使用者輸入訊息

使用者輸入簡訊、電子郵件或其他可疑文字。

例如：

「恭喜您獲得投資獎金，請立即點擊連結並輸入銀行帳號。」

### 第二階段：文字前處理

整理輸入文字，降低不必要的資料干擾。

處理項目：

- 移除多餘空白。
    
- 整理特殊符號。
    
- 統一文字格式。
    
- 保留重要文字資訊。
    

### 第三階段：NLP 特徵擷取

利用自然語言處理技術分析文字。

預計使用 TF-IDF 將文字轉換為數值向量，提供機器學習模型使用。

### 第四階段：機器學習分類

初步規劃兩種模型：

1. SVM（支持向量機）
    
2. Random Forest（隨機森林）
    

使用相同的訓練及測試資料進行比較。

### 第五階段：風險分析

根據模型輸出結果，整理訊息的分類及風險資訊。

預計分類：

- 正常訊息
    
- 可疑訊息
    
- 高風險訊息
    

注意：風險分級規則需要透過實際資料及模型結果設計，不能直接將模型分類結果當成已驗證的風險等級。

### 第六階段：結果輸出

系統顯示：

- 訊息分類結果。
    
- 風險提醒。
    
- 可疑文字特徵。
    
- 防詐建議。
    

## 四、系統流程圖

```
flowchart TD
    A[使用者輸入訊息] --> B[文字前處理]
    B --> C[TF-IDF 特徵擷取]
    C --> D[SVM 分類模型]
    C --> E[Random Forest 分類模型]
    D --> F[模型結果比較]
    E --> F
    F --> G[風險分析]
    G --> H[輸出偵測結果]
```

## 五、資料處理與模型訓練

預計執行以下步驟：

1. 蒐集正常及詐騙訊息。
    
2. 建立資料標籤。
    
3. 清理及整理文字。
    
4. 將資料分成訓練集與測試集。
    
5. 使用 TF-IDF 進行文字向量化。
    
6. 訓練 SVM 模型。
    
7. 訓練 Random Forest 模型。
    
8. 使用測試集進行模型評估。
    
9. 比較不同模型的效能。
    

## 六、模型評估指標

|評估指標|評估目的|
|---|---|
|Accuracy|整體分類正確率|
|Precision|詐騙預測結果的精確程度|
|Recall|成功找出真正詐騙訊息的比例|
|F1-score|綜合 Precision 與 Recall|

本專題特別關注 Recall，避免系統漏掉真正的詐騙訊息。

## 七、預期成果

本專題預計完成：

1. 網路詐騙知識資料庫。
    
2. 詐騙訊息文字分析流程。
    
3. NLP 文字特徵擷取功能。
    
4. SVM 與 Random Forest 分類模型。
    
5. 模型效能比較結果。
    
6. AI 網路詐騙偵測展示介面。
    

以上為預期成果，仍需透過實際開發與實驗完成驗證。

## 八、研究限制

1. 資料集的品質會影響模型表現。
    
2. 新型詐騙手法可能與既有資料不同。
    
3. 單純依靠文字特徵可能無法辨識所有詐騙。
    
4. 模型可能產生誤判。
    
5. AI 判斷不能完全取代人工確認。

## 十、個人研究反思

透過這次知識整理，我了解到 AI 網路詐騙偵測並不是單純尋找可疑關鍵字，而是需要結合資料蒐集、文字處理、特徵擷取及機器學習分類。

本專題先以 TF-IDF 搭配 SVM 作為基準，再利用 Random Forest 進行比較，希望在研究難度及實際可行性之間取得平衡。

未來可以進一步加入深度學習及更完整的語意分析技術，提高系統對不同詐騙訊息的辨識能力。
