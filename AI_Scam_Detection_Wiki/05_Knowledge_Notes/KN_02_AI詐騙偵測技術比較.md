# KN_02：AI 詐騙偵測技術比較

## 一、筆記目的

本筆記整合 AI 網路詐騙偵測、自然語言處理及機器學習相關知識，比較不同 AI 技術的用途、優點及限制。

主要探討：

1. AI 如何辨識詐騙訊息？
    
2. NLP 如何分析文字？
    
3. 不同機器學習演算法有什麼差異？
    
4. 如何選擇適合的偵測方法？
    

## 二、AI 網路詐騙偵測的主要技術

### 1. NLP（自然語言處理）

英文：Natural Language Processing

用途：

- 分析簡訊及電子郵件內容。
    
- 擷取可疑關鍵詞。
    
- 分析文字特徵。
    
- 將文字轉換成模型可以使用的資料。
    

優點：

- 可以處理大量文字訊息。
    
- 能夠協助辨識可疑文字模式。
    

限制：

- 可能無法完全理解語意及上下文。
    
- 不同詐騙手法可能使用不同表達方式。
    

### 2. TF-IDF（文字特徵轉換）

用途：

- 將文字轉換成數值向量。
    
- 計算詞語在文件中的重要程度。
    
- 作為機器學習模型的輸入。
    

優點：

- 計算方式相對簡單。
    
- 容易與傳統機器學習演算法結合。
    

限制：

- 不擅長理解詞語的深層語意。
    
- 相似意思的不同詞語可能被視為不同特徵。
    

### 3. SVM（支持向量機）

英文：Support Vector Machine

用途：

- 分析資料特徵。
    
- 建立分類邊界。
    
- 區分正常訊息與可疑訊息。
    

優點：

- 適合處理多維度特徵。
    
- 可用於文字分類問題。
    

限制：

- 參數設定會影響模型表現。
    
- 大量資料時可能增加訓練成本。
    

### 4. Decision Tree（決策樹）

用途：

- 依照不同條件進行分類。
    
- 透過分支規則判斷資料類別。
    

優點：

- 判斷過程容易理解。
    
- 可以觀察模型使用哪些特徵。
    

限制：

- 容易過度擬合。
    
- 資料變化可能影響分類結果。
    

### 5. Random Forest（隨機森林）

用途：

- 結合多棵決策樹進行分類。
    
- 綜合不同樹的預測結果。
    

優點：

- 能降低單一決策樹過度擬合的風險。
    
- 可以分析不同特徵的重要程度。
    

限制：

- 模型較不容易直接解釋。
    
- 訓練與運算成本可能較高。
    

## 三、技術比較表

|技術|主要用途|優點|限制|
|---|---|---|---|
|NLP|文字分析|處理語言資料|語意理解有限|
|TF-IDF|文字數值化|簡單快速|缺乏深層語意|
|SVM|分類|適合多維特徵|參數需要調整|
|Decision Tree|條件分類|容易解釋|容易過度擬合|
|Random Forest|集成分類|穩定性較佳|解釋較複雜|

## 四、本專題預計採用的方法

本專題初步規劃使用 NLP 結合機器學習進行詐騙訊息偵測。

預計流程：

1. 蒐集正常訊息及詐騙訊息。
    
2. 進行文字前處理。
    
3. 使用 TF-IDF 擷取文字特徵。
    
4. 分別使用 SVM 與 Random Forest 訓練模型。
    
5. 使用測試資料評估模型。
    
6. 比較不同模型的分類結果。
    
7. 選擇適合的模型。
    

目前尚未進行實際訓練，因此不預先宣稱哪個模型準確率最高。

## 五、模型評估方式

預計使用以下指標：

- Accuracy：整體預測正確率。
    
- Precision：預測為詐騙的資料中，真正詐騙的比例。
    
- Recall：實際詐騙資料中，成功被偵測的比例。
    
- F1-score：Precision 與 Recall 的綜合指標。
    

其中 Recall 特別值得關注，因為漏掉真正的詐騙訊息可能造成使用者損失。

## 六、技術選擇理由

本專題初步選擇 TF-IDF 搭配 SVM 作為基準模型，並以 Random Forest 作為比較模型。

選擇原因：

1. TF-IDF 可以將文字轉換成數值特徵。
    
2. SVM 適合進行文字分類。
    
3. Random Forest 可以提供另一種分類方法。
    
4. 透過相同測試資料比較模型，能夠觀察不同方法的優缺點。

## 八、個人分析與反思

透過不同技術的比較，我認為 AI 詐騙偵測不應只依賴單一關鍵字，而是應該結合文字特徵及機器學習分類。

本專題先採用 TF-IDF 與 SVM 建立基準模型，再利用 Random Forest 進行比較，可以讓研究範圍保持適中，也比較容易完成實驗。

未來如果有足夠資料，可以再研究深度學習模型，觀察其是否能改善語意分析能力。
